### Key Topics I Asked About
* **CSS Flexbox Debugging:** Knowing how to prevent the State bar chart and notes from being squeezed or cut off on smaller screens without page scrolling by using `flex: 0 0 auto`, `min-height: 0`, and `overflow`.
* **D3.js Accessibility (Roving Tabindex):** Learned how to create a 2-D grid navigation pattern that allows users to navigate between line chart data points and heatmap cells using arrow keys instead of repeatedly pressing Tab.
* **Colour Accessibility:** After finding the Okabe-Ito colourblind-safe hex codes that are colourblind-friendly online, I used AI to learn how to apply the colour palette to a `d3.scaleOrdinal()` to ensure that users with colour vision impairments can still identify between the eight jurisdictions.
* **KNIME Data Column:** Guidance on which nodes should be used to separate the five side-by-side tables in the raw State Excel file and gather them together.
* **Live-Region Announcers:** Knowing how to update an `aria-live="polite"` region and add an `aria-label` to D3 SVG components so that screen readers can read aloud the data values on keyboard focus.
